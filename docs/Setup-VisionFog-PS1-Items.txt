PASO 2 - SO_VisionFogConfig (assets en ScriptableObjects/Rendering/Fog/)
------------------------------------------------------------------------
  Presets: SO_VisionFog_Dark (el default del controller en Data.unity),
  SO_VisionFog_Darkness, SO_VisionFog_Light, SO_VisionFog_SilentHill.
  El escape tiene los suyos en ScriptableObjects/Escape/.

  El modelo es v2 (extincion + in-scattering). Los assets v1 se migran
  solos al cargarse (densityPower -> fogFalloffPower, playerLightIntensity
  -> playerLightClear); se puede forzar con el context menu
  "Migrate v1 values -> v2". Cada campo tiene tooltip en espanol con
  valores para probar. Los que mas se tocan:

    visionStart / visionEnd   metros sin niebla / densidad completa
    fogDensity                4.6 = en visionEnd sobrevive el 1% de la escena
    inscatterStrength         0 = oscuridad pura, 0.03-0.1 = oscuro con un
                              dejo de fogColor, 1 = Silent Hill
    playerLightRange          radio del hueco del modulo (default 8)
    playerLightClear          cuanta niebla limpia en el centro (0-1)

  El inspector del preset trae una PREVIEW (que se ve a cada distancia) y
  los botones "Aplicar como Default" / "Previsualizar" / "Limpiar preview".

  OJO: si en el Paso 3 usas "Use Light Component = true", range / clear /
  color del modulo salen de la Light real y los del preset son FALLBACK.


PASO 3 - FogLightSource SOBRE LA LUZ DEL MODULO
------------------------------------------------------------------------
  HOY NO ESTA PUESTO en Player.prefab ni en ninguna escena: el hueco sale
  del preset (playerLight...) y se centra en el pivot del player.

  El player no tiene una luz ambar unica: Player.prefab lleva tres Point
  Lights, una por modulo (LED), range 1.6, intensity 3.5. FogLightSource lee
  UNA Light. Para ponerlo:
  1. Abrir Player.prefab (Prefabs/Player.prefab).
  2. Elegir el objeto con la Light del modulo que tiene que abrir la niebla.
  3. Add Component -> "Fog Light Source".
  4. Inspector del componente:
       Light Component      -> vacio = la Light del mismo objeto.
       Use Light Component  -> CHECKED.
       Range Multiplier     -> 2  (Light.range 1.6 => fog radius ~3.2m;
                               el preset Dark usa 4.4, el default 8).
       Intensity Multiplier -> 1 (clear = saturate(intensity * mult)).
  5. Ctrl+S.

  TEST: Play -> halo claro alrededor del player. Bajar Light.range en runtime
  -> el halo se achica. Cambiar Light.color -> cambia el tinte del hueco.
  (Esto valida que la degradacion de modulos futura (2.5.1) funciona sola.)


PASO 4 - (OPCIONAL) FogLightBypass EN LAMPARAS / MONITORES
------------------------------------------------------------------------
  Lo mas simple: usar Prefabs/Light/Light Base.prefab (Spot + bypass cono
  que lee la Light + FogLightBypassPlayerFade + LightZone), o
  Light Base Switch.prefab si la prende un PoweredLightSwitch (agrega
  FogBeacon + FogLightVolume, ver Materials-System.md 6.4.1).

  A mano:
  1. Seleccionar la lampara / monitor en Hierarchy.
  2. Add Component -> "Fog Light Bypass".
  3. Radius (metros): 3-5 lamparas, 2 monitores, 8-10 generador.
     Shape: Sphere, o Cone para una Spot.
  4. Aspecto: Clear Amount = cuanta niebla disuelve; Intensity + Color =
     cuanta luz inyecta. Sin override ni Light Component usa los
     bypassDefault... del preset. Con Light Component, color e intensidad
     salen de la Light.
     OJO (bug conocido): con Light Component asignada pero APAGADA, la zona
     NO se apaga: cae al override o a los defaults del preset. Apagar la
     lampara desactivando el GameObject entero.
  5. Gizmo (esfera o cono, en el color de la zona) visible al seleccionar.

  ALTERNATIVA spec 3.4: en vez de este componente estatico, llamar
  VisionRangeController.RegisterBypass(...) desde ZoneLightController.OnActivate()
  y UnregisterBypass(...) en OnDeactivate() cuando exista ese sistema.

PASO 6 - GlitchController (CHROMATIC ABERRATION / VHS)
------------------------------------------------------------------------
  HOY NO ESTA PUESTO en ninguna escena ni prefab, y PS1Effect.mat tiene
  _ChromaticAberrationOffset = 0.00249 (CA fija, siempre prendida). Si se
  pone el glitch, dejar ese offset en 0 para que la CA sea solo el pulso.

  1. GameObject persistente (Data.unity, que ya tiene el PS1EffectApplier).
  2. Add Component -> "Glitch Controller".
  3. Inspector:
       Ps1 Material    -> arrastrar _Project/Art/Materials/Post Process/PS1Effect.mat
       Interval Range  -> (8, 45)     [spec 6.10]
       Duration Range  -> (0.1, 0.4)  [spec 6.10]
       Max CA Offset   -> 0.008
  4. Ctrl+S.

  ACCESIBILIDAD: lee PlayerPrefs "Settings_VHSGlitch" (1=on). Cuando Options
  exponga el toggle: PlayerPrefs.SetInt("Settings_VHSGlitch", v) +
  SettingsModel.RaiseSettingsApplied(). Mismo patron que PS1EffectApplier
  (Settings_CRTScanlines / Settings_PSXDithering).

  GATE POR MODALES: al abrir Inventory/SkillCheck/Examine setear
  GlitchController.SuspendTriggering = true; al cerrar, false. (spec 6.10)
  Hoy nadie lo setea.

       _PlayerPos            != (0,0,0)

     Volumes).

     flash rapido de CA. Si nunca aparece:
